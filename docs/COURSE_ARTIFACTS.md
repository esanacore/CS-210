## Public Archive Checklist

- Remove or redact student IDs, addresses, phone numbers, and account identifiers.
- Confirm any course-provided material is allowed to be shared publicly; keep it private when unclear.
- Avoid publishing full assignment prompts, rubrics, templates, solution keys, LMS screenshots, and instructor-only communications.
- Label post-course documentation and automation as later polish.
- Keep submitted code unchanged unless changes are clearly separated from the archive.
