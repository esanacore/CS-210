Project Three – The Corner Grocer Item-Tracking Program

*Summarize the project and what problem it was solving.*

This project was designed in order to address a grocery store client need.  'The Corner Grocer' decided to track their daily purchase records in the produce section, and wanted a custom-designed program to help them analyze these records so they can optimize the layout of their produce section and potentially increase sales.


*What did you do particularly well?*

Within the C++ program I designed, I utilized extensive input validation & error handling, in order to make the program more robust and secure.

*How did you make this program maintainable, readable, and adaptable?*

The scope of the project only entailed the tracking of one word grocery items (Apples, Carrots, etc.) but I decided to add functionality (via std::getline) in order to make the program more adaptable in the event that 'The Corner Grocer' decides to begin categorizing & tracking more detailed information; namely produce items with more than one word (Fiji Apples, Red Onions, etc.) along with their specific frequency.  This will help them optimize the layout of the produce section even more.  Extensive inline comments were added throughout the code, and the UI was designed to be simple & robust.
